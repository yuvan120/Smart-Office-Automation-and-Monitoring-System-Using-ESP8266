#  Smart Office Automation and Monitoring System Using ESP8266

## 📌 About the Project

Smart Office Automation and Monitoring System Using ESP8266 is an IoT-based project designed to automate and monitor essential office operations through connected devices.

Using an ESP8266 microcontroller and suitable sensors, the system can monitor office environmental conditions such as temperature, humidity, and room occupancy. It can also control electrical appliances such as lights and fans through a connected automation system.

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT platform, where users can monitor office conditions, view real-time sensor readings, and manage connected devices through an online dashboard.

This project helps improve workplace comfort, simplify office management, reduce unnecessary energy consumption, and create a smarter working environment.
